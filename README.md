# Homebrew Tale

Homebrew tap for [Tale](https://github.com/ukashazia/tale), a keyboard-first terminal application for Tailscale networks.

## Install

```sh
brew install ukashazia/tale/tale
```

## Upgrade

```sh
brew upgrade tale
```

The formula installs the prebuilt macOS release for Apple Silicon or Intel, along with Tale's manual page and shell completions.
